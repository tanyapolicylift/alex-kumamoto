## Purpose

This checklist ensures that every new employee is properly onboarded with the required security controls, policy acknowledgments, and system access. All items must be completed and documented. The completed checklist is retained in the employee's personnel file.

---

## Before Day 1

- [ ] Pre-hire checklist completed (background check passed, offer letter signed)
- [ ] Confidentiality/IP agreement signed
- [ ] Equipment ordered/prepared
- [ ] Accounts pre-provisioned (email, Slack, GitHub, cloud access per role)

## Day 1

- [ ] Device issued and registered (serial number recorded)
- [ ] Device security verified: disk encryption on, screen lock configured, OS up to date
- [ ] MFA enabled on all accounts
- [ ] Password manager set up and enrolled
- [ ] Security awareness training assigned
- [ ] Employee handbook provided and acknowledged
- [ ] Acceptable Use Policy acknowledged
- [ ] Information Security Policy acknowledged
- [ ] Code of conduct acknowledged
- [ ] Introduced to #security-incidents Slack channel and incident reporting procedure

## Week 1

- [ ] Security awareness training completed
- [ ] Access provisioned per role (least privilege -- only what is needed for the role)
- [ ] Added to org chart
- [ ] Personnel file created with all signed documents
