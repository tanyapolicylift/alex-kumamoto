## Purpose

This checklist must be completed by the hiring manager before a new hire's start date. It ensures that all required pre-employment steps -- background verification, reference checks, and offer execution -- are completed and documented before granting system access or beginning onboarding.

---

## Checklist

- [ ] Candidate qualifications reviewed and confirmed appropriate for role
- [ ] References checked (minimum 1 professional reference)
- [ ] Background check initiated via [provider -- TBD]
- [ ] Background check results received -- no disqualifying findings
- [ ] Offer letter signed
- [ ] Start date confirmed

## Open Questions

- Do we require a specific number of references? Current default is minimum 1 professional reference.
- Are there role-specific checks we should require (e.g., credit check for finance roles, education verification for engineering)?
- Which background check provider will we use? Options include Checkr, GoodHire, Sterling.
