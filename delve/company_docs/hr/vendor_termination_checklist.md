## Purpose

This checklist ensures that when a vendor relationship ends, all access is revoked, company data is recovered or destroyed, and the termination is properly documented. All items should be completed promptly upon vendor termination.

---

## Checklist

- [ ] All vendor access to PolicyLift systems revoked
- [ ] API keys, tokens, or credentials used by the vendor rotated or deleted
- [ ] Vendor confirms return or deletion of all PolicyLift data in their possession (written confirmation)
- [ ] If vendor stored Confidential/Restricted data: obtain written certification of data destruction
- [ ] Vendor removed from Vendor Inventory (or marked as terminated with date)
- [ ] Any data integrations or feeds disabled
- [ ] Team notified that vendor services are no longer available
- [ ] Contract termination documented
