# Background Check Process

| Field   | Value                      |
|---------|----------------------------|
| Date    | 2026-03-09                 |
| Version | 1.0                        |
| Owner   | Mike Levene (Head of Ops)  |

## Purpose

Ensure all new hires and contractors undergo background checks before gaining access to company systems or customer data.

## Procedure

### 1. Complete the Pre-Hire Checklist

Hiring manager completes the Pre-Hire Checklist (reference: hr/pre_hire_checklist.md) for the candidate.

### 2. Initiate Background Check

Before the start date, initiate the background check through [Checkr or similar provider -- TBD].

### 3. Access Gate

The background check must be completed -- or at minimum initiated with no disqualifying flags returned -- before the new hire is granted access to any systems or data.

### 4. Review Results

Head of Operations (Mike Levene) reviews the background check results.

- **Clear results:** Proceed with onboarding and system access provisioning.
- **Adverse findings:** Escalate to the CEO (Raghav Bansal) for a hiring decision before proceeding.

### 5. Store Documentation

Record the following in the personnel file:
- Date background check was initiated
- Date results were received
- Outcome (clear / adverse findings / decision made)

### 6. Contractors

The same process applies to contractors. If the contractor is engaged through an agency:
- Confirm that the agency conducts equivalent background checks.
- Obtain written confirmation from the agency that the check was completed.
- Store the confirmation in the contractor's file.
