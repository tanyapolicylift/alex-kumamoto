# Design Partner - Workspace Instructions
`template.md` shows the rough template generated for each Design Partner. The focus of each Design Partner files is to generate deeply-detailed context and profile to aid in solution implementation of the quote packets project.

# File Naming
For every customer, there is a file `[customer].csv` and possible a set of files `[customer]_transcript_[meeting number].csv`. The transcript files are the compilation of transcribed notes from discovery conversations (ordered by meeting number for each discovery call that was held).

## Transcript Call Participants
Any input provided by Alex Kumamoto, Raghav Bansal, or any participant labeled "PolicyLift" is representative of an employee of the internal organization and therefore should be deemphasized in transcript analysis. Any other participants are direct representatives of the customer being analyzed and quotes, timestamps, and concrete evidence should reflect their direct input and feedback.
