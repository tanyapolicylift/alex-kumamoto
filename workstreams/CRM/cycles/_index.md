# Cycle Registry

This folder contains lean startup cycles for the CRM workstream. Each cycle follows the **hypothesis → validation → learnings** pattern.

## Cycle Overview

| Cycle                                     | Hypothesis             | Status    | Outcome |
| ----------------------------------------- | ---------------------- | --------- | ------- |
| [[2026-01-cycle-01/hypothesis\|Cycle 01]] | MVP Contact Management | 🟡 Active | Pending |

## Cycle Workflow

```
1. hypothesis.md    → Define what we believe and riskiest assumptions
2. validation-plan.md → Plan how to test assumptions
3. learnings.md     → Document what we learned, decide pivot/persevere
```

## Creating a New Cycle

1. Create folder: `YYYY-MM-cycle-NN-description/`
2. Copy template files from an existing cycle
3. Link to relevant [[../confluence-refs/_index|Confluence references]]
4. Update this registry
