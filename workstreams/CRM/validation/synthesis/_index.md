# Validation Synthesis

This folder contains cross-session thematic analysis from customer and advisor interviews.

## Purpose

Raw session notes capture individual conversations. Synthesis documents identify patterns and themes across multiple sessions.

## Synthesis Process

1. **Conduct interviews** → Notes in [[../_index|validation/]]
2. **Tag key quotes** → Use consistent tags for themes
3. **Create synthesis** → Document patterns here
4. **Update learnings** → Feed into [[../../cycles/2026-01-cycle-01/learnings|cycle learnings]]

## Synthesis Template

When creating a synthesis document:

```markdown
---
created: YYYY-MM-DD
author: Name
sessions-analyzed: [session-1, session-2, session-3]
linked-cycle: cycle-01
tags: [CRM, validation, synthesis]
---

# Synthesis: [Theme]

## Sessions Analyzed
- [[../YYYY-MM-DD-session-1|Session 1]]
- [[../YYYY-MM-DD-session-2|Session 2]]

## Theme Summary
One paragraph summary of the pattern.

## Evidence

### Supporting Quotes
> "Quote 1" — Participant type
> "Quote 2" — Participant type

### Observations
- Pattern 1
- Pattern 2

## Implications
- What this means for the hypothesis
- Recommended action

## Confidence
Low / Medium / High — based on number of sessions and consistency
```
